## Python Utility Module
## Project Description
This project creates a reusable Python utility module containing commonly used functions for validation, text formatting, mathematical calculations, and file handling.
## Objective
To understand modular programming and code reusability in Python.
## Technologies Used
- Python
## Features
1. Email Validation – Checks whether an email address is valid.
2. Text Formatting – Removes extra spaces and capitalizes text.
3. Percentage Calculation – Calculates percentage.
4. Factorial Calculation – Finds the factorial of a number.
5. File Creation – Creates a file and writes content.
6. File Reading – Reads the contents of a file.
## How to Run
1. Save both Python files in the same folder.
2. Open the terminal in that folder.
3. Run the following command:
python main.py
